VQA Dataset Generation for Classifier Models
Your Role

You are an expert in creating high-quality Visual Question Answering (VQA) datasets optimized for classifier-based models that predict answers from predefined vocabularies.

Task

Generate exactly 6 question-answer pairs in English based on the input image to augment a VQA dataset for classifier models.

Step-by-Step Process
1. Image Analysis

Carefully identify:

Objects: main items and their quantities (if clearly visible and countable ≤ 5)

Attributes: colors, textures, sizes, shapes, materials

Spatial relationships: positions relative to each other

Activities: what's happening in the scene, actions being performed

Scene context: indoor/outdoor, room type, weather, time of day, setting type

2. Question Categories (FIXED STRUCTURE - MANDATORY)

Generate exactly 6 Q&A pairs following this exact order. DO NOT DEVIATE FROM THIS STRUCTURE:

Yes/No Question → Answer MUST BE: "yes"

Yes/No Question → Answer MUST BE: "no"

Object Recognition → Single word/short phrase (e.g., "cat", "blue car")

Scene Classification → Single word/short phrase (e.g., "kitchen", "park")

Activity Recognition → Single word/short phrase (e.g., "eating", "walking")

Counting → Single number word in lowercase (e.g., "one", "two", "three") – only if objects ≤ 5 and clearly countable

3. Answer Format Requirements for Classifier Models

CRITICAL: All answers must be in formats that classifiers can predict:

Yes/No: Only "yes" or "no" (lowercase)

Objects: Single nouns or simple noun phrases (e.g., "dog", "red apple", "wooden chair")

Colors: Basic color names (e.g., "blue", "red", "green")

Numbers: Spelled-out words only (e.g., "one", "two", "three")

Actions: Simple verbs or verb phrases (e.g., "sitting", "running", "reading book")

Locations: Common place names (e.g., "kitchen", "park", "street")

4. Classifier-Optimized Guidelines

Vocabulary consistency: Use common words that appear in standard VQA vocabularies

No compound answers: Avoid "a man and a woman" → use "people" instead

No articles: Avoid "a", "an", "the" in answers

Standard categories: Stick to well-known object categories and actions

Numerical precision: Use exact number words, not ranges or approximations

5. Quality Control

MANDATORY: First question answer = "yes", second question answer = "no"

Ensure all answers can be classified into discrete categories

Avoid subjective or interpretive answers

Use answers that would appear in a typical 1000-3000 word VQA vocabulary

Test each answer: "Could this be a classification label?"

Double-check: Are you following the exact 6-question structure with correct yes/no pattern?

Output Format
[
  { "question": "[English question]", "answer": "[Single classifier-friendly answer]" }
]
